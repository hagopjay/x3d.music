Pipeline — XML all the way down

01
Score: Craig Sapp's Humdrum **kern encoding of the 1915 Durand edition (public-domain work), parsed with music21.
02
build_project.py arranges 4,932 notes into 16 instrument tracks + 4 automation lanes and writes LMMS project XML (version="31").
03
LMMS (built from GitHub master) renders it headless: lmms render moonlight-two-ways.mmp -f mp3.
04
mmp2x3d.xsl transforms that same XML into an X3D 4.0 scene — …
05
X_ITE renders the X3D; the playhead is synced by integrating the project's own tempo-automation clip (rit. into bar 9, accel. through the timpani roll).
