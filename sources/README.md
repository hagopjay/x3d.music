# sources/

The notated sources, small enough to live in the repository.

- `sonata11-3.krn`: the *Alla Turca* Humdrum file, unmodified, credited in `NOTICE.md` (CC BY-NC-SA 4.0). sha256 `20986000444bfce93da6f23daf65663dfee20f25d2988c8e7635e29eb91bb0ab`.
- `ode-theme.musicxml`: the *Ode to Joy* theme, hand-encoded from the public-domain tradition (16 bars, repeat over bars 9 to 16, one tie).
- Manifests for sample libraries are added in P2. No large binaries: samples are fetched by script and checked by hash.
